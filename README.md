# 🔮 AuraBreak — Liquid Glass Brick Breaker

A modern, aesthetic reimagining of the classic arcade Brick Breaker game. Built with pure vanilla web technologies featuring a translucent **liquid glassmorphism design system**, dynamic neon lighting, mobile touch gestures, and a zero-asset **Web Audio API synthesizer**.

---

## 🎮 Live Demo
👉 **[Play AuraBreak Live](https://Dhananjaya-Dev.github.io/aurabreak-game/)**

---

## ✨ Features

- **Liquid Glass Aesthetics:** Frosted glass panels, dynamic ambient aura mesh, specular highlights, and glowing particle shattering effects.
- **Built-in Procedural Audio:** Fully synthesized sound effects using the native browser `Web Audio API` (no external MP3/WAV assets needed).
- **Multi-Screen Navigation:** Dedicated screen states for Start Menu, Active Game Canvas, Stage Victory, and Game Over.
- **Cross-Platform Responsive:** 
  - **Desktop:** Keyboard (`A`/`D`, Arrow keys) and smooth mouse tracking.
  - **Mobile & Tablets:** Fluid touch-drag control directly on the glass surface.
- **Zero Dependencies:** Pure HTML5, CSS3, and Vanilla JavaScript—no build tools or external libraries.

---

## 🕹️ Controls

| Platform | Action | Input |
| :--- | :--- | :--- |
| **Desktop** | Move Paddle Left / Right | `Arrow Left` / `Arrow Right` or `A` / `D` |
| **Desktop** | Smooth Tracking | Mouse / Trackpad Cursor |
| **Mobile** | Drag Paddle | Touch & Drag anywhere on the glass board |
| **General** | Toggle Sound | Audio toggle button on bottom-right |

---

## 🛠️ Tech Stack

- **Markup & Rendering:** HTML5 Semantic Structure & `<canvas>` 2D Context
- **Styling & Effects:** Modern CSS3 (Backdrop-filter, CSS Gradients, Flexbox)
- **Game Engine & Physics:** Native JavaScript (ES6+), `requestAnimationFrame` 60 FPS loop
- **Audio Engine:** Browser `AudioContext` (Oscillators & Gain nodes)
- **Deployment:** GitHub Pages
